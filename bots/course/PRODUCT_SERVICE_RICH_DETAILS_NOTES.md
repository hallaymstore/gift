# GiftGo — Product/Service rich details update

## Muhim
- `.env` fayli o'zgartirilmadi.
- To'lov modeli oldindan karta o'tkazma + screenshot + admin tasdiq bo'lib qoldi.

## Qo'shilganlar

### Mahsulot qo'shish alohida qilindi
Admin panelda mahsulot formasi xizmat formasidan ajratildi. Mahsulot uchun quyidagi qo'shimcha maydonlar qo'shildi:
- qisqa savdo tavsifi;
- to'liq tavsif;
- paket ichida nimalar bor;
- tarkib/material/brendlar;
- rang, ta'm, o'lcham, dizayn variantlari;
- sabab/occasion taglari;
- kimga mosligi;
- birlik va ombor soni;
- tayyorlash eslatmasi;
- saqlash/parvarish;
- yetkazish eslatmasi;
- ichki admin izoh.

### Xizmat qo'shish alohida qilindi
Xizmat formasi alohida bo'ldi. Xizmat uchun:
- xizmat formati: qo'ng'iroq, montaj, musiqa, dekor, manzilda xizmat, aralash;
- xizmat turi;
- davomiylik;
- ijrochi/operator;
- qayerda bajarilishi;
- xizmat ichiga nimalar kirishi;
- mijozdan kerak bo'ladigan ma'lumotlar;
- ssenariy prompti;
- ichki admin izoh.

### Mijoz checkout maydonlari boyitildi
Mahsulot savatda bo'lsa mahsulot tafsilotlari ko'rinadi:
- rang/tema;
- qadoqlash;
- ustiga yozuv;
- reference link;
- allergiya/yoqmaydigan narsa;
- o'xshash mahsulot bilan almashtirish roziligi;
- qo'shimcha mahsulot izohi.

Xizmat savatda bo'lsa xizmat tafsilotlari ko'rinadi:
- buyurtma beruvchi ism-familiya;
- buyurtma beruvchi telefoni;
- buyurtma beruvchi manzili;
- xizmat qabul qiluvchi ism-familiya;
- xizmat qabul qiluvchi telefoni;
- qabul qiluvchining kimligi/yoshi;
- qabul qiluvchi manzili;
- xizmat ssenariysi;
- qo'shiq/ijrochi talabi;
- qo'ng'iroq/montaj matni;
- media/material linki;
- surprise/maxfiy rejim;
- qo'shimcha xizmat talablari.

### Admin order kartasi boyitildi
Admin order kartasida endi:
- order kontent turi: PRODUCT / SERVICE / HYBRID;
- buyurtmachi;
- qabul qiluvchi;
- xizmat ssenariysi;
- mahsulot dizayn/rang/qadoq/yozuv tafsilotlari;
- qabul qiluvchiga qo'ng'iroq qilish tugmasi ko'rinadi.

### Filter
Admin buyurtmalariga PRODUCT / SERVICE / HYBRID bo'yicha filter qo'shildi.
