# Premium Compact UI Upgrade

Qo‘shilganlar:

- Mobile uchun compact premium UI: elementlar, inputlar, panel va tugmalar kichiklashtirildi.
- Border radius 4–5px atrofida qilindi.
- Pastki navbar inline SVG premium iconlarga almashtirildi.
- Mahsulot kartalari 3–4 tagacha rasmni avtomatik slider animatsiya bilan aylantiradi.
- Admin panelda mahsulot qo‘shishda:
  - asosiy rasm;
  - 3 tagacha qo‘shimcha rasm yuklash mumkin.
- Rasm yuklanmagan mahsulotlarda kategoriya/turga qarab animatsiyali SVG fallback icon chiqadi:
  - gul;
  - sovg‘a box;
  - tort;
  - shirinlik;
  - ichimlik;
  - fast food;
  - boshqa.
- Kategoriya chiplarida ham mos premium iconlar ko‘rinadi.
- Eski bitta rasmli mahsulotlar ham ishlayveradi; yangi gallery maydonlari backwards-compatible.

Eslatma:

- Mahsulot slideri uchun rasm yuklash admin paneldagi “Mahsulot qo‘shish” formasi orqali qilinadi.
- Agar mavjud mahsulotlar eski bo‘lsa, ular bitta rasm yoki fallback icon bilan chiqadi.
- Yangi qo‘shilgan mahsulotlar 4 tagacha rasm bilan premium slider ko‘rinishida chiqadi.
